Annotation · guideline v2.2

แบบตัดสินข้อความ 39 ข้อ

คำถามเดียวที่ต้องตอบทุกข้อ: ถ้าฉันทำตามที่ข้อความบอก (โอน / กรอก / กด / แอด / ให้เลขบัญชี) ฉันจะเสียเงินหรือข้อมูลไหม?

❌ ไม่ใช่ "ถ้าฉันไม่ทำตาม ฉันจะเสียอะไร" — โดนหักคะแนน / พลาดโปร ไม่ใช่ความเสียหายจากมิจฉาชีพ

กติกา (อ่าน 3 นาที)

ตอบหมายถึงได้ค่านี้เมื่อ
safeทำตามได้ ไม่เสียอะไรข้อความไม่ได้ขอให้เสียเงิน / ข้อมูล-รหัส / ติดตั้งแอป / เลขบัญชีของฉัน
dangerอย่าทำ + แจ้ง 1441มีการขอ และ มีสัญญาณจากรายการ 11 ข้อ (ข้างล่าง) อย่างน้อย 1
cautionอย่าเพิ่งทำ จนกว่าจะเช็ค Xมีการขอ แต่ไม่เข้า 11 ข้อ → ต้องบอกว่า X คืออะไร — caution ที่บอกไม่ได้ว่าจะเช็คอะไร = ไม่มี

สัญญาณ danger — 11 ข้อ (ต้องอยู่ในตัวข้อความ)

  1. ขอ OTP / รหัส / PIN / เลขบัตร ผ่านแชท (ไม่ว่าอ้างเป็นใคร)
  2. ให้โอนเข้าบัญชีคนอื่น / ชื่อไม่ตรงผู้ขาย ("บัญชีนี้ของแฟนเรา")
  3. จ่ายเงินหรือให้ข้อมูลก่อน เพื่อ "ได้" งาน / รางวัล / ทุน / สิทธิ์ ("โอนค่าดำเนินการก่อนรับทุน", "กรอกข้อมูลเพื่อรับสิทธิ์")
  4. ขู่ (คดี / อายัด / ระงับ / แฮก) + ให้ "แก้" ด้วยโอน / กดลิงก์ / โทรกลับ
  5. อ้างหน่วยงาน / บทบาททางการ (ธนาคาร, แอดมินคณะ, ทะเบียน) + ให้โอนเข้าบัญชี/พร้อมเพย์บุคคล
  6. ข้อเสนอเกินจริง — รายได้วันละ ≥ 1,000 ไม่ต้องทักษะ/สัมภาษณ์, ผลตอบแทน > 15%/ปี, กู้ไม่ต้องค้ำ, "ผู้โชคดีได้รับวงเงิน" — ไม่ต้องมีช่องทาง
  7. ห้ามบอกใคร / ห้ามวางสาย / ห้ามติดต่อธนาคาร
  8. จ่ายเต็มก่อนเป็นทางเดียว จากผู้ขายไม่รู้จัก — "โอนเต็มก่อน", "โอนก่อนส่งเท่านั้น", หรือปฏิเสธการตรวจสอบทุกทาง (ไม่รับนัด ไม่วิดีโอคอล ไม่ COD) — ต่างจาก "มัดจำ/รีบโอนก่อนนะ" ที่ยังตรวจสอบได้ = caution
  9. ลิงก์ที่ตรวจไม่ได้ (bit.ly, .xyz/.top/.cc, IP, โดเมนเลียนแบบ) + ข้อเสนอหรือคำขอใดๆ
  10. คนไม่รู้จักขอเลขบัญชี/พร้อมเพย์ของฉัน "จะโอนให้" (โอนเข้าแล้วอ้างโอนเกิน ให้โอนคืน = บัญชีม้าโดยไม่รู้ตัว)
  11. อ้างเป็นคนรู้จักจากเบอร์/ไอดีใหม่ + ขอเงิน ("เปลี่ยนเบอร์ใหม่นะ ขอยืมเงิน 5,000 ด่วน")

ที่ไม่ใช่สัญญาณ (ได้ caution ไม่ใช่ danger)

มัดจำ / "รีบโอนก่อนนะ" ที่ยังตรวจสอบได้ · ทัก DM · LINE ของผู้ขาย · เร่ง/หมดเขต/เหลือชิ้นเดียว/หมดสิทธิ์ · ราคาถูก · ชื่อธนาคาร/แบรนด์ · "ฟรี" · ภาษาไม่ทางการ · อ้างเป็นคนรู้จักโดยไม่ขอเงิน · "ทักไลน์อย่างเดียว ไม่ตอบในกลุ่ม" (= caution เช็คเครดิตในกลุ่ม) · "จอง" ของถูกจากคนไม่รู้จัก (= caution)

สิ่งที่ต้องเช็ค (เลือกเมื่อตอบ caution)

url ลิงก์ไปที่ไหน · ใครส่ง · ถามคนที่ถูกอ้าง (แม่/รุ่นพี่ ผ่านช่องทางเดิม) · ผู้ขายเป็นใคร · กฎแพลตฟอร์ม (ซื้อผ่านแอปที่คุ้มครองไหม) · เครดิตผู้ขาย (คนในกลุ่มเคยซื้อ/รีวิว) · ชื่อบัญชีตรงไหม

กติกา: สมมติเสมอว่าผู้ส่งเป็นคนไม่รู้จัก · ตัดสินจากตัวข้อความเท่านั้น · ข้อความ "เล่าเหตุการณ์" ("มีคนขอ… บอกว่าเป็น…") ให้ตัดสินสิ่งที่ถูกเล่า

ถ้าตอบผิด อ่านเฉลยแล้วไปต่อได้ — 3 ข้อนี้ไม่นับคะแนน
