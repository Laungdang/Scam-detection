🛡️ HI-Scammer — ระบบตรวจสอบมิจฉาชีพ

📌 ระบบนี้คืออะไร

HI-Scammer ช่วยตรวจสอบว่าข้อความ SMS / โทรศัพท์ / ลิงก์ / เลขบัญชี ที่คุณได้รับ มีลักษณะเป็นมิจฉาชีพหรือไม่ พัฒนาโดยใช้ Machine Learning + AI ภาษาไทย

🎯 มี 2 mode ใช้ต่างกัน

🔍 ตรวจเร็ว (ML)
วาง SMS ที่ได้รับ → ตรวจทันที (3ms) แสดง verdict + features ที่ใช้ตัดสิน เหมาะกับ "ตรวจเร็วเป็น batch"
💬 ปรึกษา AI (Q&A)
คุยกับ AI ถามต่อได้ AI เข้าใจ context — เหมาะกับ "เล่าเหตุการณ์ + ขอคำแนะนำ"

🚀 ใช้ยังไง — 3 ขั้นตอน

  1. เลือก mode ที่เหมาะกับสิ่งที่ต้องตรวจ
  2. วาง/พิมพ์ข้อความ (เบอร์โทร, เลขบัญชี, ลิงก์, SMS เต็ม) → กด Enter
  3. อ่านผลลัพธ์ + คำแนะนำ ถ้าระบบบอก "อันตราย" — อย่าทำตามที่ scam บอก, โทร 1441 (ตำรวจไซเบอร์)

🔒 ข้อมูลของคุณ (PDPA)

  • เบอร์โทร/เลขบัญชี/เลขบัตร ถูกมาส์กก่อนเก็บลง DB และก่อนส่ง AI
  • ไม่เก็บ raw PII ลง log file
  • คลิก 👁 บนผลลัพธ์ = เปิดดูค่าเต็มได้เฉพาะตัวคุณเอง (local-only)
  • ข้อมูล chat เก็บแบบ anonymous (ไม่มี user account)

📞 ต้องการความช่วยเหลือเร่งด่วน

  • ตำรวจไซเบอร์: โทร 1441 หรือ thaipoliceonline.com
  • กรมสรรพากร: โทร 1566
  • ธปท. (ธนาคารแห่งประเทศไทย): โทร 1213
  • DSI: สายด่วน 1202
